# 👻 Ghost Cloud Relay Server (خادم شبح السحابي 24/7)

خادم سحابي مستقل وخفيف جداً، يعمل على مدار الساعة لالتقاط كافة الرسائل الخاصة الواردة لحسابك على موقع `arabic.chat` وحفظها في بيئة آمنة، ثم مزامنتها تلقائياً مع **إضافة المتصفح (صندوق الشبح)** بمجرد فتح الشات بدون وسم الرسائل كمقروءة (Zero-Seen 100%).

---

## 🚀 خيارات التشغيل والنشر:

### الخيار 1: النشر المجاني عبر Render.com (أسهل وأفضل خيار - 3 دقائق)
1. قم بإنشاء حساب مجاني على موقع [Render.com](https://render.com).
2. أنشئ مستودعاً جديداً (New GitHub Repo) وارفع عليه ملفات هذا المجلد (`ghost-cloud-server`).
3. في لوحة تحكم Render:
   - اضغط **New +** ثم اختر **Web Service**.
   - اختر المستودع الخاص بك من GitHub.
   - الإعدادات:
     - **Environment**: Node
     - **Build Command**: `npm install`
     - **Start Command**: `node server.js`
     - **Plan**: Free
   - في قسم **Environment Variables** (المتغيرات):
     - `GHOST_SECRET`: اكتب كلمة سر قوية من اختيارك (مثال: `my_super_secret_99`).
     - `SITE_URL`: `https://arabic.chat`
     - `SOCKET_PATH`: `/io/`
4. اضغط **Deploy Web Service**.
5. بعد دقيقة سيصبح لديك رابط سحابي مثل: `https://ghost-cloud-xxxx.onrender.com`.
6. انسخ هذا الرابط وكلمة السر، وضعهما في إعدادات السحابة داخل الإضافة!

---

### الخيار 2: التشغيل المحلي على جهازك (Local Node.js)
إذا أردت تجربة الخادم أو تشغيله كخدمة في الخلفية على جهازك الشخصي:
```bash
# تثبيت الحزم
npm install

# تشغيل الخادم
node server.js
```
سيعمل الخادم محلياً على الرابط: `http://localhost:3000`.

## 📡 نقاط الـ API المتاحة (REST Endpoints):

| المسار | الطريقة | الوصف |
|---|---|---|
| `/` | `GET` | لوحة التحكم الرسومية Dashboard لمراقبة حالة السيرفر |
| `/api/status` | `GET` | فحص حالة الاتصال بالسوكت وعدد الرسائل المخزنة |
| `/api/sync` | `GET` | مزامنة الرسائل غير المقروءة وسحبها للإضافة (محمي بـ Secret) |
| `/api/session` | `POST` | تحديث كوكيز الجلسة والتوكن تلقائياً من الإضافة |
| `/api/test-msg` | `POST` | حقن رسالة تجريبية لاختبار المزامنة |
| `/api/clear` | `POST` | مسح سجل الرسائل المخزنة |

---

## 🔒 الأمان والخصوصية:
- كافة مسارات المزامنة محمية عبر ترويسة `x-ghost-secret` أو بارامتر `?key=...`.
- لا يمكن لأي شخص في العالم الاطلاع على الرسائل المخزنة دون معرفة المفتاح السري الذي حددته أنت.
